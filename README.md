# 🏋️‍♂️ RealMe - Fitness Center Management System

A modern and efficient management system for fitness centers and gyms — designed to handle members, trainers, workout programs, sessions, analytics, and more.

---

## 📖 Overview

**RealMe** is a full-featured web application that helps fitness centers manage their daily operations digitally.  
It covers membership management, trainer scheduling, training program creation, session organization, and business analytics — all in one platform.

---

## 🚀 Key Features

- 🔐 **User Authentication & Role Management**
  - Admin, Trainer, Receptionist, and Member roles
- 👥 **Member Management**
  - Add, update, and track member profiles, payments, and subscriptions
- 🧑‍🏫 **Trainer Management**
  - Assign trainers to programs and manage availability
- 🏃‍♂️ **Program Management**
  - Create and edit fitness or training programs
- 🗓️ **Session Management**
  - Schedule and manage training sessions and participant attendance
- 📊 **Analytics (LINQ)**
  - Revenue reports, popular programs, and active members
- 📂 **File Management**
  - Upload and manage documents or images (e.g., member photos)
- 💾 **Data Persistence**
  - Fully backed by SQL Server with Entity Framework Core

---
